# 01 需求文档（iPhone 版）

## 产品定位
iPhone 端「审美积累」：帮用户沉淀审美 + 管理穿搭。第一阶段做「骨架 + 素材」。

## 已确认决策
1. iPhone 独立应用，Mac 版保留，数据各自独立（暂不互通）
2. 第一步先做「骨架 + 素材」
3. AI 本地优先（抠图用 iPhone Vision，免费离线）
4. 数据统计先只放图标占位

## 整体结构
- 底部菜单栏（4 tab）：素材 / 搭配 / 日历 / 我的 + 中间「＋」（相机 + 相册）

## 各 tab 功能
- **素材**：复用 Mac 版「册子」体系；「＋」上传后自动跳转备注/分类
- **搭配**：抠图 → 衣橱（上装/下装/连衣裙/鞋子/包包/首饰/配饰，可自定义）→ 搭配画板（缩放/旋转/层级/多方案）→ 存素材册子
- **日历**：按天记录穿搭/妆容/姿势/滤镜、复制前一天、定位+天气+建议
- **我的**：设置、客服、AI 审美报告（可展开）、数据统计（图标占位）

## 里程碑（第一阶段）
| 里程碑 | 内容 |
|---|---|
| M0 | iOS 项目骨架 + 主题色 + 底部菜单 + 中间「＋」+ 4 占位页 |
| M1 | 数据层（模型 + 本地存储 + 图片文件） |
| M2 | 素材页（册子 + 照片网格 + 归类） |
| M3 | 中间「＋」相机/相册 → 自动跳素材备注分类 |
| M4 | 素材详情（大图 + 备注 + 分类） |

## 后续（本次不执行）
搭配、日历、我的（AI 报告/数据统计实做）、社区（第三阶段）。
